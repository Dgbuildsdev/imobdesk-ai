\# 📌 Sobre o Projeto



O \*\*ImobDesk AI\*\* é uma plataforma SaaS criada para modernizar a operação de:



\- Despachantes imobiliários

\- Imobiliárias

\- Profissionais de documentação imobiliária



A plataforma centraliza:



✅ Clientes  

✅ Imóveis  

✅ Processos imobiliários  

✅ Documentos  

✅ Tarefas  

✅ Financeiro  

✅ Comunicação  

✅ Inteligência Artificial  



Tudo em um único ambiente inteligente.
